cmi5

This page is a cmi5 assignable unit. An LMS opens it with the launch parameters in the address, the page sends initialized, relays every statement the content emits to the LMS’s LRS with the launch actor and registration, records passed or failed by the mastery score and completed when the content finishes, and terminated on Exit. The package stays on this site; the LMS holds only a course structure that names this address.

This link opens a package from . A package runs its own scripts on this site, and they can read what other packages saved in this browser. Open it only if you trust that site.

Launching it

Try a simulated launch: the same page, with a stand-in for the LMS in the page’s own script, so every statement that would reach an LRS shows in the log below instead. Answer the quiz to see failed or passed against a mastery score of 0.8, then completed, and Exit for terminated.

Download the course structure, zipped as an LMS wants it, and import it into an LMS that supports cmi5 — SCORM Cloud does, with a free tier — then open the course. It holds the structure below, naming this page and the quiz. The LMS appends its five launch parameters to the address. It names no launchMethod, so the LMS chooses where the page opens, usually in a frame of the course page, where the player runs too, Safari and iOS included. Add launchMethod="OwnWindow" to have it opened in a window of its own, for an LMS on plain http. 

<?xml version="1.0" encoding="utf-8"?>
<courseStructure xmlns="https://w3id.org/xapi/profiles/cmi5/v1/CourseStructure.xsd">
  <course id="%SITE_URL%/courses/demo-quiz">
    <title><langstring lang="en-US">h5p-offline-player: quiz</langstring></title>
    <description><langstring lang="en-US">The demo quiz, played by h5p-offline-player as a cmi5 assignable unit.</langstring></description>
  </course>
  <au id="%SITE_URL%/courses/demo-quiz/au" moveOn="CompletedAndPassed" masteryScore="0.8">
    <title><langstring lang="en-US">Quiz</langstring></title>
    <description><langstring lang="en-US">A four-question quiz on how the player works.</langstring></description>
    <url>%SITE_URL%/demo/cmi5.html?src=%SITE_URL%/demo/content/quiz.h5p</url>
  </au>
</courseStructure>

For a page and package of your own, write a structure like it with your own ids and address, zip it as cmi5.xml and import the zip. The package URL must send CORS headers, as for any setup; this site’s content does. Instead of ?src=, the structure can carry the URL in <launchParameters>, which the page reads from the LMS.
