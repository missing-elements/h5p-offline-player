@missing-elements/h5p-offline-player

Self-hosted H5P in one web component. Paste a link to a .h5p file below, or pick one from disk, and it plays on this page.

Host it yourself Get the offline app

  • No H5P server Static hosting is enough: no backend, no third-party service in between.
  • Nothing unpacked The archive is read in place, its files served by a Service Worker.
  • Any export Exports without their libraries play with a pinned pack, untrusted ones as checked data.
  • Learning records xAPI that names the package's build, save and resume, and cmi5.

The package plays with its own libraries, as on the site that made it.
