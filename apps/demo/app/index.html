Open an H5P file

Pick a .h5p from your computer, or drop it on this page. It is read in place, on this device — nothing is uploaded. Install the app and it works with no network, and opens .h5p files from your file manager. Installing needs Chrome or Edge; in other browsers this page plays files all the same, it just cannot be installed.

Drop the .h5p file to open it

A package that does not carry its own libraries — what h5p.com and h5p.org export by default — needs them from the H5P hub, which takes a network. Everything else plays offline. Files you open are not kept: open one again next time, and what was already extracted comes from this device's cache.
