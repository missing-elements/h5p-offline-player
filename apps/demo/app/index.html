An H5P player that works offline

H5P Offline Player is a web app you install from the browser — a PWA — that plays .h5p files without Moodle, WordPress, Lumi or any other server. Teachers hand out the files; learners open them here, at home or in class, with or without a connection.

Install it

  • In Chrome or Edge on Windows, macOS, Linux or ChromeOS, press Install app above, or the install icon at the end of the address bar.
  • On Android, open this page in Chrome and choose Install app from the menu.
  • Safari and Firefox cannot install it, but this page plays files in them all the same while online.

Open a file

  • Press Open file, or drop a .h5p on the page.
  • Once installed, the app opens .h5p files from your file manager: double-click one, or use Open with.
  • A link to /app/?src= and a package's address opens that package in the app, for a teacher sending a course by link.

What works offline

  • The player, the H5P runtime and its fonts are stored on install.
  • The app carries the H5P libraries for every content type on the H5P hub, about 10 MB, so a package exported without its own — what h5p.com and h5p.org do by default — plays offline too. Only a package that needs a newer version than the app carries asks to fetch it from h5p.org, once.
  • Files are read on this device and never uploaded. They are not kept either: open one again next time, and what was already extracted comes from this device's cache.

What it keeps on this device, and what it does not

  • Where you were. When a file is open, the content saves its own state — the slide or chapter reached, the answers given so far, the position in a video, whatever that content type keeps — in this browser's storage, on this device only. Open the same file again (same name, size and date) and it picks up there; Start over forgets it. On a shared device, the next person to open the file finds where the last one left it, so press Start over first. The app sends none of it anywhere. A package's own scripts can read it, though, including what other packages saved here, so the app asks before opening a package from another site's link; open only packages you trust.
  • Not results. The scores and completions the content reports as xAPI statements are neither stored on this device nor sent anywhere, so nothing here is a record that a course was completed.
  • For results that are recorded — a class, a course, a compliance record — use the player component on a site that sends its xAPI statements to an LRS or an LMS.
