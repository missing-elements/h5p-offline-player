# Dictation (H5P.Dictation)

The learner hears sentences and types them; the content compares what was typed word by word.

- Each item of `sentences` is a recording, `sample`, and the `text` it says. A slower recording can go in `sampleAlternative`.
- Alternative spellings of a word: `colour|color`.
- `behaviour.tries` limits how often a recording plays.

## Example

```json
{
  "type": "H5P.Dictation",
  "params": {
    "taskDescription": "Listen, then write what you hear.",
    "sentences": [
      { "sample": [{ "path": "sentence1.mp3" }], "text": "The river flows to the sea." },
      { "sample": [{ "path": "sentence2.mp3" }], "text": "The bridge is old." }
    ]
  }
}
```
