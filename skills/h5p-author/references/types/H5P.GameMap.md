# Game Map (H5P.GameMap)

A map with stages, each holding exercises; finishing a stage opens the stages joined to it.

- `gamemapSteps.backgroundImageSettings.backgroundImage` is the map.
- Each item of `gamemapSteps.gamemap.elements` is a stage: a `label`, its exercises under `contentsList` (`[{ "contentType": { "library": "…", "params": { … } } }]`), its `neighbors` named by label, and `telemetry.x` and `telemetry.y`, its place in percent of the map from the top left. The build joins neighbours both ways, sets the ids the map keeps, and spreads out stages written without a place.
- At least one stage has `canBeStartStage: true`.
- `behaviour.lives` and `behaviour.timeLimitGlobal` make it a game; leave them out for a plain path.

## Example

```json
{
  "type": "H5P.GameMap",
  "params": {
    "gamemapSteps": {
      "backgroundImageSettings": { "backgroundImage": { "path": "valley.png" } },
      "gamemap": {
        "elements": [
          {
            "label": "Source",
            "canBeStartStage": true,
            "telemetry": { "x": 15, "y": 20 },
            "neighbors": ["Mouth"],
            "contentsList": [{ "contentType": { "library": "H5P.TrueFalse", "params": { "question": "A river can begin at a glacier.", "correct": "true" } } }]
          },
          {
            "label": "Mouth",
            "telemetry": { "x": 75, "y": 70 },
            "contentsList": [{ "contentType": { "library": "H5P.MultiChoice", "params": { "question": "Where does a river end?", "answers": [{ "text": "In a sea or a lake", "correct": true }, { "text": "In the mountains", "correct": false }] } } }]
          }
        ]
      }
    }
  }
}
```
