# Timeline (H5P.Timeline)

Events along a time line, each with a date, a headline and a text, browsed in order.

- `timeline.headline` and `timeline.text` make the title slide; each item of `timeline.date` is an event.
- Dates are written `YYYY,MM,DD`, the month and day optional: `"1888"`, `"1888,7,22"`. An event with an `endDate` spans a period; `timeline.era` shades longer periods.
- An event's `asset.media` is a web address (a YouTube video, a Wikipedia article, a picture's URL) that the timeline loads from that site when shown. That site then learns who views it; tell the user, or leave media out.

## Example

```json
{
  "type": "H5P.Timeline",
  "params": {
    "timeline": {
      "headline": "Bridges over the Danube in Budapest",
      "text": "From the first permanent bridge to the newest.",
      "date": [
        { "startDate": "1849,11,20", "headline": "Chain Bridge", "text": "The first permanent bridge between Buda and Pest." },
        { "startDate": "1876,4,30", "headline": "Margaret Bridge", "text": "The second permanent bridge." },
        { "startDate": "1896", "headline": "Liberty Bridge", "text": "Opened for the millennium celebrations." }
      ]
    }
  }
}
```
