# Questionnaire (H5P.Questionnaire)

A survey: open questions and multiple-choice questions with no right answer, then a thank-you screen. Not scored.

- Each item of `questionnaireElements` holds its question under `library`, which is itself sub-content: `{ "library": { "library": "H5P.SimpleMultiChoice", "params": { … } }, "requiredField": true }`.
- H5P.SimpleMultiChoice: `question` (plain text), `inputType` `"radio"` (one answer) or `"checkbox"` (several), `alternatives` of `{ "text": "…" }`.
- H5P.OpenEndedQuestion: `question`, `placeholderText`, `inputRows` `"1"`, `"2"`, `"3"` or `"10"`.
- The answers go out as xAPI statements; nothing stores them unless the site does.

## Example

```json
{
  "type": "H5P.Questionnaire",
  "params": {
    "questionnaireElements": [
      {
        "library": {
          "library": "H5P.SimpleMultiChoice",
          "params": { "question": "How often do you walk by a river?", "inputType": "radio", "alternatives": [{ "text": "Every week" }, { "text": "Sometimes" }, { "text": "Never" }] }
        },
        "requiredField": true
      },
      { "library": { "library": "H5P.OpenEndedQuestion", "params": { "question": "Which river do you know best, and why?", "inputRows": "3" } } }
    ]
  }
}
```
