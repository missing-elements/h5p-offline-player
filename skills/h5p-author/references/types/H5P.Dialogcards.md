# Dialog Cards (H5P.Dialogcards)

Flash cards: a prompt on the front, the answer on the back, turned by the learner. Not scored.

- Each item of `dialogs` is a card: `text` on the front, `answer` on the back, optionally an `image` with its `imageAltText`, an `audio` track and `tips`.
- `mode: "repetition"` brings back the cards a learner got wrong, until they know them all.

## Example

```json
{
  "type": "H5P.Dialogcards",
  "params": {
    "title": "Rivers in German",
    "dialogs": [
      { "text": "the river", "answer": "der Fluss", "image": { "path": "river.png" }, "imageAltText": "A river between hills" },
      { "text": "the bridge", "answer": "die Brücke", "tips": { "front": "It crosses the river." } }
    ]
  }
}
```
