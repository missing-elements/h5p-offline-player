# Interactive Book (H5P.InteractiveBook)

A book of chapters with a table of contents, each chapter a page of text, media and questions, and a summary of the learner's progress at the end.

- Each item of `chapters` is a page, sub-content of H5P.Column: `{ "library": "H5P.Column", "metadata": { "title": "…" }, "params": { "content": [ … ] } }`. Its `metadata.title` is the chapter's name in the table of contents, and is required. Write the page's `content` as H5P.Column's file says.
- A cover: `showCoverPage: true`, with `bookCover.coverDescription` and, optionally, `bookCover.coverMedium` (H5P.Image or H5P.Video).
- The summary page lists every question and its score. Played on a site that records results, the book reports its own result only with the site's reporting turned on.

## Example

```json
{
  "type": "H5P.InteractiveBook",
  "params": {
    "chapters": [
      {
        "library": "H5P.Column",
        "metadata": { "title": "Where rivers begin" },
        "params": { "content": [{ "content": { "library": "H5P.AdvancedText", "params": { "text": "A river begins at its source: a spring, a lake or a glacier." } } }] }
      },
      {
        "library": "H5P.Column",
        "metadata": { "title": "Check yourself" },
        "params": { "content": [{ "content": { "library": "H5P.TrueFalse", "metadata": { "title": "Sources" }, "params": { "question": "Every river begins at a spring.", "correct": "false" } } }] }
      }
    ]
  }
}
```
