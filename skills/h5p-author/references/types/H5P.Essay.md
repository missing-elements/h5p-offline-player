# Essay (H5P.Essay)

The learner writes a text, scored by the keywords it contains, with feedback per keyword and a sample answer to compare.

- Each item of `keywords` is a word or phrase to look for, with its `alternatives`, and `options` for its points and feedback. `*` matches any characters; `/…/` is a regular expression.
- A sample solution: `solution.sample`, shown after the learner submits.
- `behaviour.minimumLength` and `behaviour.maximumLength` bound the answer in characters.
- Keyword scoring cannot judge an argument: say so to the user, and keep the essay's weight low where it counts.

## Example

```json
{
  "type": "H5P.Essay",
  "params": {
    "taskDescription": "In two or three sentences, explain how a river reaches the sea.",
    "keywords": [
      { "keyword": "downhill", "alternatives": ["down hill", "gravity"], "options": { "points": 1, "feedbackMissed": "Say what makes the water move." } },
      { "keyword": "sea", "options": { "points": 1, "feedbackMissed": "Say where the river ends." } }
    ],
    "solution": { "sample": "Water flows downhill under gravity, gathering into streams and then a river, which ends in the sea." }
  }
}
```
