# Branching Scenario (H5P.BranchingScenario)

A story in which the learner's choices lead to different paths and endings: decisions, conversations, procedures.

- `branchingScenario.content` is the list of nodes, numbered from 0 in order; the scenario starts at node 0.
- A node's `type` is sub-content: text, an image, a video, a presentation, or a choice (H5P.BranchingQuestion). Every node that is not a choice says where it goes in `nextContentId`: the number of the next node, or `-1` to end the scenario there.
- A choice: `{ "library": "H5P.BranchingQuestion", "params": { "branchingQuestion": { "question": "…", "alternatives": [{ "text": "…", "nextContentId": 3 }] } } }`, each alternative leading to a node or an end.
- An end shows `endScreens[0]`; give a node `feedback` (`title`, `subtitle`, `endScreenScore`) for an ending of its own. More end screens are numbered `-2`, `-3`… in order, and a `nextContentId` can name one.
- The build refuses a link to a node that does not exist and a loop with no way out, and notes a node nothing leads to.

## Example

```json
{
  "type": "H5P.BranchingScenario",
  "params": {
    "branchingScenario": {
      "title": "Crossing the river",
      "startScreen": { "startScreenTitle": "Crossing the river", "startScreenSubtitle": "Choose a way across." },
      "content": [
        { "type": { "library": "H5P.AdvancedText", "params": { "text": "You reach a river after heavy rain. The water is high and fast." } }, "nextContentId": 1 },
        {
          "type": {
            "library": "H5P.BranchingQuestion",
            "params": { "branchingQuestion": { "question": "How do you cross?", "alternatives": [{ "text": "Wade across here", "nextContentId": 2 }, { "text": "Walk to the bridge", "nextContentId": 3 }] } }
          }
        },
        { "type": { "library": "H5P.AdvancedText", "params": { "text": "The current knocks you over. Never wade into fast water." } }, "nextContentId": -1, "feedback": { "title": "Swept away", "endScreenScore": 0 } },
        { "type": { "library": "H5P.AdvancedText", "params": { "text": "The bridge takes longer, and you cross safely." } }, "nextContentId": -1, "feedback": { "title": "Safely across", "endScreenScore": 1 } }
      ],
      "endScreens": [{ "endScreenTitle": "The end" }]
    }
  }
}
```
