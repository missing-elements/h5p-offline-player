# Summary (H5P.Summary)

The learner builds a summary statement by statement, picking the true one from each group.

- In each item of `summaries`, the first of `summary` is the true statement; the others are false. The content shuffles them.
- Each group should test one point; the true statements, in order, read as the summary.

## Example

```json
{
  "type": "H5P.Summary",
  "params": {
    "intro": "Choose the correct statement.",
    "summaries": [
      { "summary": ["Rivers flow from higher to lower ground.", "Rivers flow from lower to higher ground."] },
      { "summary": ["Most rivers end in a sea or a lake.", "Most rivers end in a mountain spring."] }
    ]
  }
}
```
