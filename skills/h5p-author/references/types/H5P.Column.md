# Column (H5P.Column)

A page of content one below another: text, pictures, video and questions, in the order written. Called "Page" in the editor.

- Each item of `content` is `{ "content": { "library": "…", "params": { … } } }`, sub-content of any library the Fields section lists. Write each from its type file: H5P.AdvancedText, H5P.Image and H5P.Video have files of their own.
- `useSeparator` draws a line between items: `"auto"`, `"enabled"` or `"disabled"`.

## Example

```json
{
  "type": "H5P.Column",
  "params": {
    "content": [
      { "content": { "library": "H5P.AdvancedText", "params": { "text": "<h2>The water cycle</h2><p>Rain falls, rivers carry it to the sea, and the sun lifts it again.</p>" } } },
      { "content": { "library": "H5P.Image", "params": { "file": { "path": "cycle.png" }, "alt": "Rain, a river and the sea" } } },
      { "content": { "library": "H5P.TrueFalse", "metadata": { "title": "Rivers and the sea" }, "params": { "question": "Rivers carry water to the sea.", "correct": "true" } } }
    ]
  }
}
```
