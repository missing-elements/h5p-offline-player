# Accordion (H5P.Accordion)

Text in panels that open on a click, for reference material a learner looks up. Not scored.

- Each item of `panels` has a plain `title` and its `content`, sub-content of H5P.AdvancedText: `{ "library": "H5P.AdvancedText", "params": { "text": "…" } }`.

## Example

```json
{
  "type": "H5P.Accordion",
  "params": {
    "panels": [
      { "title": "Source", "content": { "library": "H5P.AdvancedText", "params": { "text": "Where a river begins." } } },
      { "title": "Mouth", "content": { "library": "H5P.AdvancedText", "params": { "text": "Where a river ends, in a sea or a lake." } } }
    ]
  }
}
```
