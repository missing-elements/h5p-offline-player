# Image Sequencing (H5P.ImageSequencing)

Pictures shown shuffled, which the learner puts in order: stages of a process, ages of a thing.

- Write `sequenceImages` in the right order, at least three, each with `image` and `imageDescription`; the content shuffles them.

## Example

```json
{
  "type": "H5P.ImageSequencing",
  "params": {
    "taskDescription": "Put the river's course in order, from source to sea.",
    "sequenceImages": [
      { "image": { "path": "source.png" }, "imageDescription": "A spring in the mountains" },
      { "image": { "path": "valley.png" }, "imageDescription": "A river in a valley" },
      { "image": { "path": "delta.png" }, "imageDescription": "A delta at the sea" }
    ]
  }
}
```
