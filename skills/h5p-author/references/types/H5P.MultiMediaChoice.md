# Image Choice (H5P.MultiMediaChoice)

A multiple-choice question whose answers are pictures.

- Each item of `options` holds its picture as sub-content under `media`, `{ "library": "H5P.Image", "params": { "file": { "path": "…" }, "alt": "…" } }`, and `correct`. The alternative text is what a screen reader reads as the answer: write it as the answer.
- `behaviour.questionType` `"single"` or `"multi"`, as for Multiple Choice; `behaviour.aspectRatio` fits pictures of different shapes.

## Example

```json
{
  "type": "H5P.MultiMediaChoice",
  "params": {
    "question": "Which picture shows a river delta?",
    "options": [
      { "media": { "library": "H5P.Image", "params": { "file": { "path": "delta.png" }, "alt": "A delta" } }, "correct": true },
      { "media": { "library": "H5P.Image", "params": { "file": { "path": "source.png" }, "alt": "A spring" } }, "correct": false }
    ]
  }
}
```
