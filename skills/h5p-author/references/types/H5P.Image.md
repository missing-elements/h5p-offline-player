# Image (H5P.Image)

A picture, a part other content holds: in a page, a book, a slide, a hotspot or an answer. Not a content type on its own.

- `file` is the picture, a file beside the source (`.png`, `.jpg`, `.gif`) or a web address of one; the build reads its size.
- `alt` is required: what the picture shows, for a learner who cannot see it. A picture that only decorates is `"decorative": true` instead.

## Example

```json
{
  "type": "H5P.Column",
  "params": {
    "content": [
      { "content": { "library": "H5P.Image", "params": { "file": { "path": "delta.png", "copyright": { "license": "CC BY", "author": "Ann Author" } }, "alt": "A river delta seen from above" } } }
    ]
  }
}
```

## Fields of H5P.Image 1.1

- `file` image file, required — Image
- `decorative` boolean = false — Decorative only
- `alt` text, required; only when decorative is false — Alternative text: Required. If the browser can't load the image this text will be displayed instead. Also used by "text-to-speech" readers.
- `title` text — Hover text: Optional. This text is displayed when the users hover their pointing device over the image.

3 interface texts are left out: they come from the libraries' translations. `h5p-author schema H5P.Image --all` lists them, for a source to set one.
