# Memory Game (H5P.MemoryGame)

Cards face down, turned two at a time, until every pair is found.

- Each item of `cards` is a pair: `image` and `imageAlt`, and, for a pair of two different pictures, `match` and `matchAlt`. Without `match` the pair is two copies of `image`.
- `description` is shown when the pair is found: say what it shows.
- Square-ish pictures work best; at least two cards.

## Example

```json
{
  "type": "H5P.MemoryGame",
  "params": {
    "cards": [
      { "image": { "path": "danube.png" }, "imageAlt": "The Danube in Budapest", "description": "The Danube flows through four capitals." },
      { "image": { "path": "thames.png" }, "imageAlt": "The Thames in London", "description": "The Thames flows through London." }
    ]
  }
}
```
