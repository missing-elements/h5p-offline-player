# Sort the Paragraphs (H5P.SortParagraphs)

Paragraphs shown shuffled, which the learner puts in order: steps of a process, events of a story.

- Write `paragraphs` in the right order, at least three; the content shuffles them.
- Scoring: `behaviour.scoringMode` `"positions"` counts paragraphs in the right place, `"transitions"` each one that follows the right one.

## Example

```json
{
  "type": "H5P.SortParagraphs",
  "params": {
    "taskDescription": "Put the journey of a raindrop in order.",
    "paragraphs": [
      "Rain falls on the mountains.",
      "Streams gather the water.",
      "A river carries it through the valley.",
      "The river reaches the sea."
    ]
  }
}
```
