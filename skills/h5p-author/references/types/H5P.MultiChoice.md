# Multiple Choice (H5P.MultiChoice)

One question, two or more answers, one or several of them correct, with feedback per answer.

- Mark the right answers with `"correct": true`. `behaviour.type` is `"single"` (radio buttons, exactly one correct), `"multi"` (checkboxes) or `"auto"`, which picks by how many are correct.
- Feedback for an answer goes in its `tipsAndFeedback.chosenFeedback`, shown after Check when it was chosen. Write it for every answer, wrong ones especially: say why.
- A pass mark: `behaviour.passPercentage`, with `overallFeedback` ranges for each score band, `{ "from": 0, "to": 99, "feedback": "…" }`.
- Answers are shuffled unless `behaviour.randomAnswers` is false.

## Example

```json
{
  "type": "H5P.MultiChoice",
  "params": {
    "question": "Which river is the longest in Europe?",
    "answers": [
      { "text": "Volga", "correct": true, "tipsAndFeedback": { "chosenFeedback": "Right: about 3,530 km." } },
      { "text": "Danube", "correct": false, "tipsAndFeedback": { "chosenFeedback": "The Danube is second, about 2,850 km." } },
      { "text": "Rhine", "correct": false, "tipsAndFeedback": { "chosenFeedback": "The Rhine is about 1,230 km." } }
    ],
    "behaviour": { "type": "single" }
  }
}
```
