# Find the Hotspot (H5P.ImageHotspotQuestion)

A picture in which the learner clicks the right area: a part of a diagram, a place on a map.

- `imageHotspotQuestion.backgroundImageSettings` is the picture.
- Each item of `imageHotspotQuestion.hotspotSettings.hotspot` is an area: `computedSettings` holds `x`, `y`, `width` and `height` in percent of the picture from its top left, and `figure`, `"rectangle"` or `"circle"`; `userSettings.correct` says whether it is the right one, and `userSettings.feedbackText` what a click on it says. At least one is correct.
- `hotspotSettings.noneSelectedFeedback` is said for a click outside every area.

## Example

```json
{
  "type": "H5P.ImageHotspotQuestion",
  "params": {
    "imageHotspotQuestion": {
      "backgroundImageSettings": { "path": "delta.png" },
      "hotspotSettings": {
        "taskDescription": "Click the river's mouth.",
        "hotspot": [
          { "computedSettings": { "x": 60, "y": 55, "width": 20, "height": 20, "figure": "circle" }, "userSettings": { "correct": true, "feedbackText": "Yes: here it meets the sea." } },
          { "computedSettings": { "x": 10, "y": 10, "width": 25, "height": 25, "figure": "rectangle" }, "userSettings": { "correct": false, "feedbackText": "That is upstream." } }
        ],
        "noneSelectedFeedback": "Look where the river widens into the sea."
      }
    }
  }
}
```
