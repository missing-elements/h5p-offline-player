# Single Choice Set (H5P.SingleChoiceSet)

Quick questions, one after another, each with one right answer of two to four; the learner moves on at the first click.

- In each item of `choices`, the first of `answers` is the right one; the set shuffles them when shown.
- Keep answers short: they are buttons.

## Example

```json
{
  "type": "H5P.SingleChoiceSet",
  "params": {
    "choices": [
      { "question": "Which sea does the Danube reach?", "answers": ["Black Sea", "North Sea", "Baltic Sea"] },
      { "question": "Which river flows through Paris?", "answers": ["Seine", "Loire", "Rhône"] }
    ]
  }
}
```
