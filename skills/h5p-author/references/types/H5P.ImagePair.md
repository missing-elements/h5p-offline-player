# Image Pairing (H5P.ImagePair)

Two columns of pictures; the learner drags each one on the left onto its match on the right.

- Each item of `cards` is a pair: `image` with `imageAlt`, and `match` with `matchAlt`.
- `behaviour` is one setting, whether to offer Retry: `true` or `false`.

## Example

```json
{
  "type": "H5P.ImagePair",
  "params": {
    "taskDescription": "Match each river to its city.",
    "cards": [
      { "image": { "path": "danube.png" }, "imageAlt": "The Danube", "match": { "path": "budapest.png" }, "matchAlt": "Budapest" },
      { "image": { "path": "thames.png" }, "imageAlt": "The Thames", "match": { "path": "london.png" }, "matchAlt": "London" }
    ]
  }
}
```
