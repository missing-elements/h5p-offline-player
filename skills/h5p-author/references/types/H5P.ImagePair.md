# Image Pairing (H5P.ImagePair)

Two columns of pictures; the learner drags each one on the left onto its match on the right.

- Each item of `cards` is a pair: `image` with `imageAlt`, and `match` with `matchAlt`.
- `behaviour` is one setting, whether to offer Retry: `true` or `false`.

## Example

```json
{
  "type": "H5P.ImagePair",
  "params": {
    "taskDescription": "Match each river to its city.",
    "cards": [
      { "image": { "path": "danube.png" }, "imageAlt": "The Danube", "match": { "path": "budapest.png" }, "matchAlt": "Budapest" },
      { "image": { "path": "thames.png" }, "imageAlt": "The Thames", "match": { "path": "london.png" }, "matchAlt": "London" }
    ]
  }
}
```

## Fields of H5P.ImagePair 1.4

The example is `type` and `params` alone, and `params` holds the fields below. A source also names its own `title`, `language`, `license` and `authors`, all four required: the build refuses a source that leaves out any of them. Write the author and the licence the user gave, as given, and ask for neither: an author not given is the name you know the user by, or "Unknown", and a licence not given is `U`; never make up a name. A licence is an H5P code, `U`, `CC BY`, `CC BY-SA`, `CC BY-ND`, `CC BY-NC`, `CC BY-NC-SA`, `CC BY-NC-ND`, `CC0 1.0`, `CC PDM`, `GNU GPL`, `PD`, `ODC PDDL` or `C`, with any version apart: "CC BY 4.0" is `"license": "CC BY", "licenseVersion": "4.0"`.

- `taskDescription` text = "Drag images from the left to match them with… — Task Description: A guide telling the user how to solve this task.
- `cards` list 2–100 of, required — Cards
  - `image` image file, required — Image
  - `imageAlt` text, required — Alternative text for Image: Describe what can be seen in the photo. The text is read by text-to-speech tools needed by visually impaired users.
  - `match` image file — Matching Image
  - `matchAlt` text — Alternative text for Matching Image: Describe what can be seen in the photo. The text is read by text-to-speech tools needed by visually impaired users.
- `behaviour` boolean = true — Behavioural settings

4 interface texts are left out: they come from the libraries' translations. `h5p-author schema H5P.ImagePair --all` lists them, for a source to set one.
