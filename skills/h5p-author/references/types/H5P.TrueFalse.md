# True/False Question (H5P.TrueFalse)

One statement the learner marks true or false.

- `correct` is the text `"true"` or `"false"`, not a boolean.
- Write the statement as a claim, not a question, so either answer is a judgement of it.
- `behaviour.feedbackOnCorrect` and `behaviour.feedbackOnWrong` replace the default messages; say why.

## Example

```json
{
  "type": "H5P.TrueFalse",
  "params": {
    "question": "The Danube flows through four capital cities.",
    "correct": "true",
    "behaviour": {
      "feedbackOnCorrect": "Yes: Vienna, Bratislava, Budapest and Belgrade.",
      "feedbackOnWrong": "It does: Vienna, Bratislava, Budapest and Belgrade."
    }
  }
}
```
