Embedding the player page

For a site that cannot host even one file. The player runs on its own origin, so a hostile archive reaches the player's data and not the embedding site's. Storage is partitioned per embedding site.

Safari blocks Service Workers in cross-origin iframes and the player cannot run without one, so on Safari the embed degrades to a link.

Markup

<iframe src="https://player.example/embed?src=https://host.example/course.h5p"
        allow="fullscreen"></iframe>
